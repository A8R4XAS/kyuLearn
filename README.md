# kyuLearn
**Akupunktur-Quiz** ist ein interaktives Lernspiel für Web und Android zum Einprägen von Akupunkturpunkten. Auf einer Körperansicht werden Punkte als antippbare Marker angezeigt – zunächst ohne Namen. Erst beim Tippen erscheinen Name, Code und Meridian. Mit React, TypeScript und Vite entwickelt, funktioniert das Quiz responsiv auf jedem Bildschirm.
